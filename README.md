Netflix Data Analysis Using Python
Project Overview
This project analyzes Netflix movies and TV shows using Python, Pandas, NumPy, Matplotlib, and Seaborn. It includes data cleaning, exploratory data analysis, visualization, trend analysis, and business insights.

This project was completed as part of the Data Analysis Using Python internship at Auspify Technologies.
Dataset Information
- Total Records: 8,790
- Total Columns: 10
- Movies: 6,126
- TV Shows: 2,664
- Duplicate Records: 0
Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
Tasks Completed
Task 1: Data Cleaning and Preparation
- Inspected the dataset.
- Identified and handled missing values.
- Checked duplicate records.
- Standardized text columns.
- Saved the cleaned dataset.
Task 2: Content Type Analysis
- Analyzed Movies and TV Shows.
- Created bar charts and pie charts.
- Movies represent 69.69% of the content.
- TV Shows represent 30.31% of the content.
Task 3: Country-Wise Content Analysis
- Analyzed Netflix content by country.
- Identified the top 10 countries.
- Created country-wise visualizations.
- United States leads with 3,240 titles.
- India ranks second with 1,057 titles.
Task 4: Release Year Trend Analysis
- Analyzed content by release year.
- Created yearly trend visualizations.
- Identified 2018 as the highest release year with 1,146 titles.
Task 5: Content Rating and Genre Analysis
- Analyzed content ratings.
- Identified the most popular genres.
- TV-MA is the most common rating with 3,205 titles.
- International Movies is the leading genre with 2,752 titles.
Task 6: Netflix Business Insights
- Summarized Netflix content distribution.
- Identified the top country and genre.
- Analyzed yearly content releases.
- Created a business insights report.

How to Run
1. Download or clone the project.
2. Install dependencies using pip install -r requirements.txt.
3. Open Jupyter Notebook.
4. Run the six notebooks in order, from Task 1 to Task 6.
